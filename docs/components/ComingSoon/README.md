# ComingSoon

The teaser page before launch: logo, the eyebrow "Extraordinary talent. Everyday solutions.", the headline "Coming soon.", the line "Los Angeles Call Sheet" and one button, "Get on the call sheet". It sits on a curved panel over the quiet Europium backdrop, lit by a mint horizon glow; the button and field glow on hover and focus.

## The consumer provides

- `ctaHref`: where "Get on the call sheet" goes (the sign-up form or page). Optional `onCta` for analytics or to open a sign-up dialog.
- `links` for the footer (social, Privacy, Terms, contact) and `copyright`. Take both from the live site; the template invents none.

## Use when

- A product or city that isn't open yet. Keep it this simple: no countdown, no feature list.
- It is a dark-theme island in either theme. The backdrop is `backdrop-europium` (see MATERIALS.md).

Template (atomic design). See README.md, Components.
